# 数字电子技术基础知识要点

## 第1章 数制与码制

### 数制
数字电路中常用二进制、八进制、十六进制。任意进制数 R 的第 i 位权值为 R^i。二进制数 (1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11。二进制转换为十六进制时，整数部分从低位起每 4 位一组，每组转换为一位十六进制数；小数部分从高位起每 4 位一组，不足补零。

### 数制转换方法
十进制整数转二进制用"除 2 取余，倒序排列"；十进制小数转二进制用"乘 2 取整，正序排列"。例如 13 转二进制：13÷2=6 余 1，6÷2=3 余 0，3÷2=1 余 1，1÷2=0 余 1，倒序得 1101。

### BCD 码
8421BCD 码用 4 位二进制数表示 1 位十进制数，0000~1001 对应 0~9。例如十进制 35 的 8421BCD 码为 0011 0101。BCD 码中 1010~1111 是非法码。

### 其他常用码
格雷码（Gray Code）的特点是相邻两个码组之间只有一位不同，常用于避免过渡干扰。余 3 码是 8421BCD 码加上 3 得到的无权码。

## 第2章 逻辑代数基础

### 三种基本逻辑运算
与运算：Y = A·B，只有 A、B 都为 1 时 Y 为 1。或运算：Y = A+B，只要有一个输入为 1，Y 就为 1。非运算：Y = A'，输出与输入相反。与非门输出为 Y = (A·B)'，或非门输出为 Y = (A+B)'，异或运算 Y = A⊕B = A'B + AB'，同或运算 Y = A⊙B = AB + A'B'。

### 逻辑代数的基本定律
交换律：A·B = B·A，A+B = B+A。结合律：(A·B)·C = A·(B·C)。分配律：A·(B+C) = AB + AC，A + BC = (A+B)(A+C)。吸收律：A + AB = A，A + A'B = A + B，A·(A+B) = A。反演律（德摩根定律）：(A·B)' = A' + B'，(A+B)' = A'·B'。双重否定律：(A')' = A。0-1 律：A·0 = 0，A·1 = A，A+0 = A，A+1 = 1。互补律：A·A' = 0，A + A' = 1。

### 逻辑函数化简方法
常用方法有公式化简法和卡诺图化简法。公式化简利用基本定律消去多余因子和多余项，如 F = AB + AB' = A(B+B') = A。卡诺图化简的原则：相邻的 1 格可以圈成 2 的整数次幂的矩形圈，圈越大越优，每个圈对应一个乘积项，最后得到最简与或式。

### 逻辑函数的两种标准形式
最小项之和（积之和形式）与最大项之积（和之积形式）。n 变量逻辑函数有 2ⁿ 个最小项，最小项 m₃ 表示变量组合使函数值为 1 的情况，F = Σm(1,3,5,7) 表示这些最小项之和。

## 第3章 逻辑门电路

### 基本门电路
与门、或门、非门是三种基本门电路。常用集成门电路系列有 TTL（晶体管-晶体管逻辑）和 CMOS（互补金属氧化物半导体）。TTL 高电平约 3.6V，低电平约 0.3V；CMOS 电路功耗低、抗干扰能力强、输入阻抗高。

### 集电极开路门（OC 门）与三态门
OC 门需要外接上拉电阻才能正常工作，多个 OC 门输出可以并联实现线与功能。三态门的输出有高电平、低电平、高阻态三种状态，高阻态用使能控制，常用于总线结构。

## 第4章 组合逻辑电路

### 组合逻辑电路分析
组合逻辑电路的特点是输出只取决于当前输入，没有记忆功能。分析步骤：(1) 从输入到输出逐级写出逻辑表达式；(2) 化简；(3) 列出真值表；(4) 说明逻辑功能。例如三人表决电路，多数同意则输出 1，可用与非门实现。

### 常用组合逻辑器件
编码器（如 74LS148 优先编码器）、译码器（如 74LS138 3-8 译码器，可译码实现任意组合逻辑函数）、数据选择器（如 74LS151 8 选 1）、加法器（半加器、全加器）、数值比较器。用译码器和与非门可以实现任意组合逻辑函数。

### 半加器与全加器
半加器实现两个一位二进制数相加，输出本位和 S 与进位 C：S = A⊕B，C = AB。全加器还要考虑低位进位 Ci，S = A⊕B⊕Ci，C = AB + Ci(A⊕B)。

## 第5章 触发器

### 触发器概述
触发器是具有记忆功能的时序逻辑基本单元，有两个稳定状态（0 态和 1 态）。按其逻辑功能分为 RS 触发器、D 触发器、JK 触发器、T 触发器。

### 各种触发器的特性方程
RS 触发器（约束条件 RS=0 不能同时为 1）：Q(n+1) = S + R'Q(n)。D 触发器：Q(n+1) = D，只随输入变化，最常用。JK 触发器：Q(n+1) = JQ' + K'Q，无约束条件，功能最全。T 触发器：Q(n+1) = TQ' + T'Q，当 T=1 时翻转，T=0 时保持。

### 触发器的触发方式
电平触发（高电平或低电平触发）、边沿触发（上升沿或下降沿触发）。边沿触发只在时钟边沿瞬间采样输入，抗干扰能力强，是实际集成电路的主要形式。

## 第6章 时序逻辑电路

### 时序逻辑电路的特点与分析方法
时序逻辑电路由组合电路和触发器组成，输出不仅与当前输入有关，还与电路原状态有关。分析方法：写出时钟方程、驱动方程、状态方程，列状态转换表，画状态转换图，说明功能。

### 寄存器
寄存器用于暂存二进制数据，由触发器构成。移位寄存器可以在时钟作用下将数据逐位左移或右移，可实现串并转换。

### 计数器
计数器按计数进制分为二进制计数器、十进制计数器、任意进制计数器；按计数方向分为加法计数器和减法计数器。用集成计数器（如 74LS161 四位二进制同步计数器）可以通过置零法或置数法构成任意进制计数器。计数器是数字系统中最常用的时序器件。

### 同步与异步计数器
同步计数器所有触发器共用一个时钟，工作速度快，但电路复杂；异步计数器各触发器时钟不同级，结构简单但工作速度慢、有过渡状态。

## 第7章 555 定时器

### 555 定时器的基本结构
555 定时器由两个电压比较器、一个基本 RS 触发器、一个放电管和分压电阻组成。它有三种典型应用电路：施密特触发器（波形整形）、单稳态触发器（定时、延时）、多谐振荡器（产生方波）。

### 555 定时器的应用
多谐振荡器无需输入信号即可输出矩形波，振荡周期 T = 0.7(R1 + 2R2)C。单稳态触发器输出脉冲宽度 tw = 1.1RC。

## 第8章 数模与模数转换

### 数模转换器（DAC）
DAC 将数字量转换为模拟量。常见类型有权电阻网络 DAC、倒 T 型电阻网络 DAC。输出电压与输入数字量成正比：Vo = Vref × D / 2ⁿ。

### 模数转换器（ADC）
ADC 将模拟量转换为数字量。常见类型有逐次逼近型 ADC 和双积分型 ADC。转换过程包括采样、保持、量化、编码。分辨率表示能分辨的最小模拟量，n 位 ADC 分辨率为 Vref / 2ⁿ。
